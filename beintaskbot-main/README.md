# CRM Smart Assistant

CRM Smart Assistant — веб-платформа BeinSystems для компаний, которые ведут
сделки в Kommo и хотят работать с задачами, клиентами, сотрудниками и
уведомлениями в одном кабинете.

## Два изолированных контура

- `/webapp` — существующий внутренний кабинет BeinSystems. Его данные и
  настройки не используются для клиентов платформы.
- `/register`, `/setup`, `/app` — кабинет нового клиента. Каждая компания
  получает собственный `tenant_id`; сделки, задачи, сообщения, уведомления,
  OAuth-токены и аудит изолированы на уровне PostgreSQL.

## Первый запуск клиента

1. Владелец регистрирует компанию через Telegram на `/register`.
2. AI-помощник помогает выбрать модули и сценарий работы.
3. Владелец подключает Kommo через OAuth и выбирает нужные воронки и этапы.
4. В `/app` появляются только выбранные данные Kommo; браузер читает быстрый
   кэш PostgreSQL, а не выполняет новый запрос к Kommo при каждом поиске.
5. Владелец создаёт ссылку приглашения сотрудника. Сотрудник подтверждает
   Telegram, владелец подтверждает запрос, и только после этого открывается
   доступ к кабинету. Telegram ID вручную не нужен.

## Railway variables

Никогда не храните реальные значения в Git. Полный перечень есть в
`.env.example`. Для нового клиентского контура обязательны:

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | PostgreSQL Railway |
| `TENANT_ENCRYPTION_KEY` | Fernet-ключ для шифрования OAuth-токенов Kommo |
| `KOMMO_OAUTH_CLIENT_ID` | Public Kommo integration client ID |
| `KOMMO_OAUTH_CLIENT_SECRET` | Секрет public Kommo integration |
| `KOMMO_OAUTH_REDIRECT_URI` | `https://crm.pro.az/api/platform/integrations/kommo/callback` |
| `CANONICAL_WEB_ORIGIN` | `https://crm.pro.az` |

Старые переменные (`KOMMO_TOKEN`, WhatsApp, Telegram, VAPID и OpenAI) пока
нужны внутреннему BeinSystems-контуру и не должны переноситься в tenant-данные.

## SaaS-аудит и целевая архитектура

Публичная документация с картой текущих жёстко заданных правил, моделью
tenant/роль/воронка, политиками задач и планом рефакторинга доступна по адресу
`/documentation` на основном домене.
