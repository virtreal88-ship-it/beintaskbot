# Безопасная подготовка AI Agents staging

Railway service и PostgreSQL должны быть отдельными от production. В Kommo существующие webhook не редактировать; отдельную staging-подписку добавлять только после отдельного разрешения и проверки staging endpoint.

## Ограничение обработки

Staging webhook получает события аккаунта, но сохраняет и ставит в очередь только события, которые совпадают с полной подтверждённой Test Mode-привязкой: tenant, Kommo account, канал, контакт, сделка, talk_id и chat_id. Проверки только по номеру телефона недостаточно. До появления всех идентификаторов Test Mode остаётся заблокированным.

Вебхук может доставить на staging события других диалогов. Они должны завершаться без записи в очередь и без вызовов AI. Worker повторно проверяет привязку и актуальное состояние чата. Исходящее сообщение менеджера отменяет ответ AI.

## Безопасные настройки по умолчанию

На staging оставить Manual-режим, автоотправку и CRM-действия выключенными. Включить общий kill switch можно только после проверки отдельной тестовой базы и схемы. Kill switch должен останавливать приём новых заданий, очередь и любые внешние действия.

Для Test Mode задать AI_AGENTS_TEST_CLIENT_PHONE и AI_AGENTS_TEST_COMPANY_PHONE только в Railway Variables staging. Эти значения не хранятся в репозитории; если хотя бы одно отсутствует, сервер отклоняет привязку.

## Подключение webhook после отдельного разрешения

1. Подготовить staging service, отдельную PostgreSQL, HTTPS URL и проверенный health endpoint.
2. Убедиться, что webhook endpoint включён только в staging, схема успешно создана, Test Mode показывает blocked до полной привязки, а отправка и CRM-действия выключены.
3. В Kommo добавить отдельную webhook-подписку на https://<staging-host>/webhook/kommo/ai-agents-test для входящих и исходящих сообщений.
4. Не менять и не удалять существующие webhook. Сразу после сохранения сравнить их прежние URL и события.
5. Сначала использовать Manual-режим и только после отдельного разрешения отправить одно тестовое сообщение в привязанный диалог.

До подтверждения точных идентификаторов и разрешения владельца не подключать staging webhook и не отправлять сообщения.
